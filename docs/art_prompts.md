# 그림 목록과 ChatGPT 그림 문장

《트로네 공작가의 아델라인》의 도트 그림을 일러스트로 바꾸기 위한 목록이에요. 회색 상자 안의 문장을 그대로 복사해서 ChatGPT에 붙여 넣으면 돼요.

---

## 0. 먼저 알아 둘 것

**ChatGPT에서 그리는 순서**
1. 새 대화를 열고, 처음 그리신 "로판 영애" 그림을 **첨부**한 채 아래 「공통 그림체」 문장을 먼저 보내요.
2. 같은 대화에서 그림 문장을 하나씩 보내요.
3. 인물은 **기본 표정을 먼저** 그린 뒤, 같은 대화에서 「표정 바꾸기」 문장으로 나머지 표정을 그려요. 같은 대화 안에서 그려야 얼굴이 덜 바뀌어요.
4. 인물 한 명(한 나이)마다 대화를 새로 여는 게 좋아요. 배경은 배경끼리 한 대화에서 그려도 돼요.

**나이 구간** (소설 줄거리 기준)

| 구간 | 장 | 아델라인 | 다른 아이들 |
|---|---|---|---|
| 10대 초반 | 1~14장 | 10~13세 | 12~13세 안팎 |
| 10대 중반 | 15~25장 | 13~17세 | 15~17세 |
| 10대 후반 | 26~30장 | 18세 | 18~20세 |

어른(공작·집사·선생님 등)은 나이가 거의 그대로라 한 번씩만 그리면 돼요.

**다 그린 그림을 저에게 주는 방법**
- 사파리에서 github.com/lewfot-crypto/rofan 에 들어가 `Add file → Upload files` 로 올려 주세요. 파일 이름은 안 바꿔도 되고, 올린 뒤 "목록 몇 번부터 몇 번까지 순서대로"라고만 말씀해 주시면 제가 보고 정리할게요.
- 이 대화에 그림을 붙이시면 제가 볼 수는 있는데, 파일로 저장할 수 있는지는 아직 확인하지 못했어요. 처음 한 장으로 시험해 보면 좋겠어요.
- 그림이 들어갈 자리(코드)는 그림이 오기 시작하면 제가 만들게요.

## 1. 공통 그림체 (대화마다 맨 처음에 한 번)

```
지금부터 그리는 그림은 모두 같은 게임에 들어갈 그림이야. 첨부한 그림과 같은 그림체로 계속 똑같이 맞춰 줘.
- 한국 로맨스 판타지 웹툰 표지풍 일러스트
- 부드러운 채색, 섬세한 머리카락 결, 은은한 빛과 가장자리 빛, 맑은 피부
- 19세기 유럽 귀족 시대(빅토리아·벨 에포크 풍)의 옷과 집
- 아이와 10대는 반드시 나이에 맞게 그려 줘. 어른 같은 얼굴, 화장, 몸매 강조는 하지 말고 앳된 얼굴 비율로.
- 글자, 로고, 서명, 워터마크는 넣지 마.
```

## 2. 인물 공통 형식 (인물 문장 뒤에 붙여 보내기)

```
형식: 세로 2:3, 전신(머리끝부터 신발 끝까지 잘리지 않게), 인물 한 명만, 정면에서 살짝 비스듬히 서서 팔은 자연스럽게 내린 자세. 배경은 투명(PNG). 투명이 안 되면 아무것도 없는 순백색 배경. 바닥 그림자 없이.
```

## 3. 표정 바꾸기 (같은 대화에서)

```
방금 그린 인물과 완전히 같은 사람, 같은 옷, 같은 자세, 같은 크기와 위치로 다시 그려 줘. 표정만 ○○로 바꿔 줘. 배경은 계속 투명.
```

○○에 넣을 말:
- **웃음**: 부드럽게 웃는 얼굴
- **슬픔**: 눈썹이 처지고 눈가가 촉촉한 얼굴
- **걱정**: 미간을 살짝 찌푸린 걱정스러운 얼굴
- **놀람**: 눈을 크게 뜨고 입을 살짝 벌린 얼굴

```
인물: 13세 소녀. 금빛 머리를 높게 올려 묶음, 호박색 눈, 인형처럼 완벽한 자세와 웃는 법을 배운 얼굴. 흰색과 연보라색 드레스.
```
- 10대 중반 (15세) (기본·웃음·슬픔·놀람 → 4장)
```
인물: 15세 소녀. 금빛 머리를 높게 올림, 호박색 눈, 완벽하지만 지친 얼굴. 흰 드레스, 왼손목에 하얀 리본.
```
- 18세 (4권) (기본·웃음 → 2장)
```
인물: 18세 소녀. 금빛 머리를 높게 올림, 호박색 눈, 훈련되지 않은 자연스러운 웃음. 흰 드레스, 가방 손잡이처럼 손목에 하얀 리본.
```
- 소설은 올림머리·호박색 눈이에요. 지금 게임 도트는 내린 머리·보랏빛 눈이에요(사용자 결정으로 도트는 그대로 둠). 일러스트는 소설대로 적었어요.

## 5. 배경 (필수 33장)

**배경 공통 형식** (배경 문장 뒤에 붙여 보내기)
```
형식: 가로 3:2, 사람은 한 명도 없이. 눈높이 시점, 화면 아래쪽 3분의 1쯤에 바닥이 보이고 가운데는 인물이 설 수 있게 비워 둬. 실내의 창밖은 계절이 너무 드러나지 않게 커튼이나 흐린 하늘로.
```
- 장소는 모두 **트로네 공작가의 대저택**(규모가 큰 공작 저택)이에요.

| 번호 | 장소 | 그릴 것 |
|---|---|---|
| B1~B4 | 저택 앞 | 가을 낮 / 여름 낮 / 눈 덮인 겨울 낮 / 눈 내리는 겨울 밤 |
| B5~B6 | 현관 홀 | 낮 / 밤 |
| B7~B8 | 아델라인의 방 | 낮 / 밤 |
| B9~B10 | 식당 | 낮 / 밤 |
| B11~B12 | 공작의 서재 | 낮 / 밤 |
| B13~B14 | 부엌 | 낮 / 밤 |
| B15 | 공부방 | 낮 |
| B16~B17 | 이층 복도 | 낮 / 밤 |
| B18~B19 | 집사실 | 낮 / 밤 |
| B20~B21 | 마차 안 | 낮 / 밤 |
| B22~B25 | 과수원 돌담 | 겨울 / 여름 / 사과꽃 핀 봄 / 봄 달밤 |
| B26~B28 | 정원 | 여름 낮 / 가을 달밤의 테라스 / 겨울 |
| B29~B30 | 황궁 정원 | 봄 / 여름 |
| B31~B32 | 무도회장 | 불 켜진 무도회 / 불 꺼진 밤 |
| B33 | 살롱(남의 집 응접실) | 낮 |

**장소별 문장**

B1~B4 저택 앞
```
트로네 공작가 대저택의 정면. 크림색 돌로 지은 3층 본관과 양쪽 날개, 가운데 기둥 현관과 넓은 대리석 계단, 앞마당의 분수와 자갈길, 맨 앞의 검은 철문. 이층 가장 왼쪽 창 하나에만 불이 켜져 있음. [가을 낮, 붉고 노란 나무 / 여름 낮, 짙은 초록 / 눈 덮인 겨울 낮 / 눈 내리는 겨울 밤, 모든 창의 불이 꺼지고 달빛]
```
- 대괄호 [ ] 안에서 하나씩 골라 네 번 그려요. 아래도 같아요.
- 마지막 겨울 밤(B4)은 29장 "그 창의 불이 처음으로 꺼졌다" 장면이라 **이층 가장 왼쪽 창도 꺼진** 그림이에요.

B5~B6 현관 홀
```
대저택의 현관 홀. 2층까지 트인 높은 천장, 가운데에서 양쪽으로 갈라지는 대리석 계단, 큰 크리스털 샹들리에, 기둥, 벽의 초상화. [낮, 높은 창으로 들어오는 빛 / 밤, 샹들리에와 촛대의 따뜻한 불빛만]
```

B7~B8 아델라인의 방
```
아델라인이 열 살부터 열여덟 살까지 쓰는 소녀의 침실. 나무 벽과 바닥, 푸른 휘장이 드리운 침대, 창가의 작은 책상과 회색 노트, 둥근 러그, 작은 벽난로. 소박하지만 정성스럽게 꾸민 방. [낮 / 밤, 창밖은 별, 책상 위 촛불과 벽난로 불빛만]
```

B9~B10 식당
```
대저택의 식당. 아주 긴 식탁, 양 끝에 의자 하나씩, 반대편 끝 의자 앞에도 식기가 놓여 있음, 샹들리에, 높은 창, 찬장의 은식기. [낮 / 밤, 촛대 불빛]
```

B11~B12 공작의 서재
```
공작의 서재. 벽을 덮은 책장, 창가의 큰 책상과 지도, 선반 위의 작은 호두나무 상자, 큰 책상 옆 창가에 놓인 작은 호두나무 책상, 벽난로. [낮 / 밤, 책상 위 등불과 벽난로 불빛, 창밖은 밤하늘]
```

B13~B14 부엌
```
대저택의 넓은 부엌. 가운데 큰 화덕, 걸려 있는 구리 냄비, 나무 작업대 위의 호두와 밀가루, 찻잎 통, 주전자. [낮 / 밤, 화덕의 불빛만]
```

B15 공부방
```
가정교사 수업을 하는 공부방. 큰 지도가 걸린 벽, 지구의, 책장, 나무 책상 두 개, 창가의 커튼, 늦가을 오후의 빛.
```

B16~B17 이층 복도
```
대저택의 이층 복도. 길게 이어지는 카펫과 문들, 벽의 촛대, 끝에 있는 서재 문. [낮 / 밤, 촛대 몇 개와 서재 문 아래 틈으로 새는 따뜻한 불빛]
```

B18~B19 집사실
```
집사실. 장부가 빽빽한 책장, 정돈된 책상, 벽시계, 열쇠 꾸러미, 반쯤 열린 서랍. [낮 / 밤, 책상 위 촛불 하나]
```

B20~B21 마차 안
```
귀족 마차의 안쪽. 남색 벨벳으로 누빈 좌석, 금빛 단추, 붉은 커튼을 묶은 큰 창, 창밖으로 지나가는 풍경. [낮, 창밖은 들판 / 밤, 창밖은 별이 뜬 하늘]
```

B22~B25 과수원 돌담
```
저택 뒤편 과수원. 사과나무들 사이로 낮은 돌담이 이어지고, 담 너머로 이웃 집 지붕이 조금 보임. 담 위에 사람이 앉을 수 있을 만한 자리. [눈 쌓인 겨울 / 짙은 초록 여름 / 하얀 사과꽃이 핀 봄 / 사과꽃 핀 봄 달밤, 돌담 위에 작은 등불 하나]
```

B26~B28 정원
```
대저택의 정원. 장미 덤불, 산책로, 하얀 양산을 편 둥근 탁자와 의자, 돌 난간이 있는 테라스. [여름 낮, 귀족 영애들의 정원 모임 자리 / 가을 달밤의 테라스, 멀리 창 불빛 / 겨울, 유리 온실이 보이는 정원]
```

B29~B30 황궁 정원
```
황궁의 정원 다과회 자리. 흰 천막, 다과가 차려진 긴 탁자, 멀리 보이는 하얀 황궁, 잘 다듬은 화단. [봄, 꽃이 핀 나무 / 여름, 짙은 초록]
```

B31~B32 무도회장
```
황실 무도회장 같은 큰 홀. 높은 아치 창, 기둥, 거울 판넬, 크리스털 샹들리에 셋, 체크무늬 대리석 바닥, 이층으로 오르는 계단과 층계참. [촛불과 샹들리에가 모두 켜진 화려한 무도회 / 불이 꺼진 밤, 달빛만 들어옴]
```

B33 살롱
```
다른 귀족 가문의 응접실. 장밋빛 다마스크 벽지, 대리석 벽난로와 금테 거울, 소파 둘, 찻상, 초상화, 높은 창.
```

**아델라인 (선택, 인물 사전·실행 화면용)**: 게임은 아델라인의 눈으로 보는 이야기라 장면에는 아델라인이 나오지 않아요. 인물 사전이나 실행 화면에 쓰고 싶으시면 그려 주세요.
- 10대 초반 (10세)
```
인물: 10세 소녀. 은빛 머리를 길게 한 갈래로 땋아 어깨 앞으로 늘어뜨림, 푸른 보랏빛 큰 눈, 조용히 관찰하는 눈빛, 키가 작고 볼이 둥근 앳된 얼굴. 흰 깃이 달린 단정한 푸른 드레스, 회색 노트를 두 손으로 안고 있음.
```
- 10대 중반 (15세)
```
인물: 15세 소녀. 은빛 머리를 길게 땋음, 푸른 보랏빛 눈, 차분하고 단단해진 얼굴. 단정한 푸른 드레스, 팔에 파란 가죽 지도책.
```
- 18세 (성인식)
```
인물: 18세 소녀. 은빛 머리를 땋아 올림, 푸른 보랏빛 눈, 조용하지만 분명한 얼굴. 장식이 적은 짙은 푸른 드레스, 소매 끝에 회색 실로 작은 노트 모양 자수.
```

**그 밖에 소설에만 나오는 인물 (선택)**: 황제, 황후, 발트하임 백작 부인.
