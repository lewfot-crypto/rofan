# Claude Code에게 이렇게 말하세요 (복사해서 붙여 넣기)

## 0. 준비
1. 압축을 풀고 터미널에서 그 폴더로 이동 → `claude` 실행
2. 미리 보기: `dist/game.html` 을 더블클릭(브라우저). 폴더에 `preview/adeline-game-preview.html` 도 들어 있어요.

## 1. 첫 지시 (현재 상태 파악)
```
CLAUDE.md, docs/canon.md, docs/roadmap.md 를 읽고 아래를 해 줘.
1) 이 프로젝트를 네가 이해한 대로 5줄 이내로 요약
2) npm install, npm test 를 실행해서 지금 상태가 정상인지 확인
3) 결과를 알려 주고, 내가 선택해야 할 중요한 결정이 있으면 먼저 질문해 줘
아직 코드는 고치지 마.
```

## 2. 1권 4~9장 만들기 (결정은 묻고, 한 장씩 확인)
```
docs/roadmap.md 의 "1권 4~9장 장면화"를 진행하자.
규칙: 한 번에 한 장씩. 장 하나를 시작하기 전에 분기 설계 초안(알아차림 → 어떤 선택지/장면이 달라지는지)을
나한테 보여 주고 승인받아. 장이 끝나면 npm run build 후 dist/game.html 로 내가 직접 해 볼 수 있게 알려 줘.
CLAUDE.md의 "의사결정 규칙"을 따라 중요한 결정은 반드시 물어봐. 4장부터 시작해.
```

## 3. 다음 장으로
```
4장 잘 봤어. 이대로 5장 진행해. 5장도 분기 설계 초안부터 보여 줘.
```
수정이 필요하면: `4장에서 ○○가 어색해. △△로 바꿔 줘.` 처럼 **어느 장면의 무엇이 어떻게 보이는지**만 말하면 돼요. (모바일이면 화면 캡처 첨부)

## 4. 새 기능 (예: 노트 줄 긋기)
```
노트에 적은 한 줄을 나중에 줄 그어 취소하는 기능을 넣고 싶어.
6장에서 "나는 이 집에서 내 것을 가질 수 없다"를 적고, 8장에서 그 줄에 선을 긋는 흐름이야.
구현 방법이 여러 개면 화면 예시와 함께 선택지로 보여 줘.
```

## 5. 그림 바꾸기 (Flow 등으로 만든 이미지가 생겼을 때)
```
이 이미지들로 배경/인물을 교체하고 싶어. (파일 첨부 또는 폴더 경로)
CLAUDE.md의 "그림 교체" 방식대로 부분 교체가 되게 해 주고,
교체 전/후 스크린샷을 비교해서 보여 줘. 화면 비율이 안 맞으면 어떻게 할지 먼저 물어봐.
```

## 6. 버그가 보일 때
```
[장면 id 또는 장 이름]에서 [무슨 일이 일어났는지].
기대한 것: [원래 어떻게 보여야 하는지]. 화면: [캡처 첨부, 기기와 화면 크기]
원인을 찾아서 고치고, 같은 문제가 다시 안 생기게 테스트도 추가해 줘.
```

## 7. 이럴 땐 이렇게
- 방향이 헷갈리면: `지금 선택지를 2~3개로 정리해서 추천과 함께 보여 줘.`
- 너무 많이 바꾸려 하면: `범위를 줄여서 [장 하나]만 해. 나머지는 다음에.`
- 작업 끝: `오늘 한 일과 남은 일을 docs/roadmap.md 에 반영해 줘.`
