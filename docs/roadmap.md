# 로드맵

## 1. 1권 4~9장 장면화 (완료)
현재 `c3f`/`c3g` 의 `next:'send'` 를 `c4a` 로 바꾸고, 9장 끝에 새 `send` (endTitle: "1권까지 읽었어요")를 둔다.
단락은 `node tools/dump_paras.js 4` 처럼 목록을 보고 `chapters.js` 에서 그대로 가져온다. 장면마다 알아차림 후보와 조건부 분기를 최소 1개 둔다.

**4장 〈불 켜진 서재 앞의 찻잔〉** (place: corridor/kitchen, 겨울) — ✅ 구현 완료(c4a~c4h). 승인된 추가 분기: "말씀하셔도 돼요"(`mayTell`), "외투를 입을게요"(`tookCoat`). 다음 장 연결: `c4h → send` 를 `c5a` 로.
- 복도에서 불빛·종이 소리(노트: 펜이 멈췄다 이어짐) → 선택: 노크하려다 손을 내린다 / 더 듣는다
- 부엌 주전자(노트: 아무도 안 마시는데 치우지 않음, 찻잎 통이 가장 많이 열린 흔적) → **설탕 두 조각 / 넣지 않는다** (플래그)
- 아침에 잔이 닦여 돌아옴(반쯤 마심) → 닷새째 밤 마로트와 마주침: 말씀드릴 건가요? / 원하지 않아요(또는 말씀하셔도 돼요)
- 마로트의 "단 것을 드시지 않습니다"(설탕 선택에 따라 반응 다름) → 설탕 없는 차 → 빈 잔이 손잡이를 아델라인 방 쪽으로 돌려 놓인 채 돌아옴(노트) → "집사는 날씨만 말씀드립니다"

**5장 〈과수원 담장 너머〉** (orchard, 겨울, chars: adrian) — ✅ 구현 완료(c5a~c5g). 다음 장 연결: `c5g → send` 를 `c6a` 로.
- 길 잃음(탠지 설명은 늘 간단하다 노트) → 담 위의 아드리안(노트: 낙엽 밟는 소리가 정직하게 한 사람 몫 / 잉크 묻은 손가락 / 둘째 아들)
- "성은?" → **트로네 / 에버하트 / 대답을 삼킨다** (플래그 → 아드리안 반응이 다름, 소설은 "다음에 알려 줘")
- 차를 건넬지 선택 → 8년째 꺼지지 않는 서재 불(노트) → 내일도 오라는 말

**6장 〈유품 상자〉** (corridor → study, chars: edric) — ✅ 구현 완료(c6a~c6g, 서재 책상 위 상자 소품 `props:['box']`, 선택으로 노트 적기 `note:`). 다음 장 연결: `c6g → send` 를 `c7a` 로.
- 문이 열려 있음(노트) → 들어감 → 상자 뚜껑에 먼지 하나 없음(노트 `dustless`, **8장에서 쓰임**) → 안경을 집어 든다 / 뚜껑만 열고 거둔다
- 에드릭: "내려놓아라 … 나가라 … 아이를 방으로" (노트: 상자를 안는 손이 떨렸다. 분노로 읽음)
- 방에서 **노트에 "나는 이 집에서 내 것을 가질 수 없다"를 적는다 / 쓰지 못한다** (적으면 `misread` 노트 생성)
- 과수원 담 아래, 아드리안이 겨울 사과를 건넴

**7장 〈마로트의 침묵〉** (office, 겨울, chars: marot) — ✅ 구현 완료(c7a~c7j). 승인된 추가 선택: 시계를 묻기(`askedWatch`), 마지막 줄 적기(`maybeNot`). 다음 장 연결: `c7j → send` 를 `c8a` 로.
- 질문 규칙: 마로트는 거짓말 안 함, 아델라인은 예/아니오로만 묻는다 (첫날 사과의 말은 "의역"이었다)
- "상자는 제가 온 날 함께 온 건가요?" → 침묵 = 아니오 → "저 때문이 아니라 상자 때문에?" 
- **1장에서 `notebook`(서랍의 노트)을 알아챘다면** 마로트가 회색 노트 규격 이야기(에드릭이 주문서에 서명) 공개. 못 알아챘다면 "새벽 네 시까지 안경을 쥐고 계셨다"만 말함.
- 서랍 속 회중시계: `clock`(4장 …1권 s4) 알아챘다면 홀트의 말과 연결해 "자기 것이 아니라서 안 차는 시계", 아니면 성만 읽음.
- 밤에 마로트의 방 앞에 찻잔을 둔다

**8장 〈봄, 처음 불린 이름〉** (bedroom → study, 봄) — ✅ 구현 완료(c8a~c8h, 줄 긋기 `cross:`, `S.crossed`). 다음 장 연결: `c8h → send` 를 `c9a` 로.
- 탠지가 머리를 땋아 주며 소문(마르타): 상자는 8년 전부터 서재, 공작이 직접 닦음. `dustless` 를 알아챘다면 "빼앗은 게 아니었네요" 선택지가 열림.
- 서재 문을 두드림 → "아델라인." → "그날은 미안했다." → 선반 위 찻잔 열한 개
- **`misread` 노트에 줄을 긋는다**(취소선) → 새 노트 "나는 오늘 처음으로 틀렸다. 그리고 틀린 것이 기뻤다."

**9장 〈여름 끝의 손님〉** (여름, exterior/dining, chars: gregor, kylen, marot) — ✅ 구현 완료(c9a~c9i). 1권 끝 카드 `send`. 카일런 그림을 소설대로(뒤로 넘긴 검은 머리, 오른손 장갑)
- 아침 식탁 "빵이 식는다" → 북부 대공 부자 도착 → 식탁에서 카일런의 무례 → **"……장갑, 안 벗으세요?" / 아무 말도 하지 않는다**(2권 카일런과의 관계 플래그) → "에버하트의 딸이로군" → 에드릭의 포크가 멈춤(노트)

### 구현해야 할 앱 기능
- `S.crossed = {}` (노트 취소선), choice 필드 `note:'id'`(선택으로 노트 생성), `cross:'id'`(노트 줄 긋기, 이미 그었으면 숨김). 노트 탭에서 `crossed` 는 `<del>` 로 표시.
- 새 배경 `corridor`(이층 복도: 문 아래 새는 불빛, 촛대), `office`(집사실: 장부 책장, 책상, 서랍 속 은시계). `PLACES` 에 `corridor:'이층 복도'`, `office:'집사실'` 추가 → 저택 탭 썸네일이 10개가 된다.
- 필요한 인물 스프라이트는 이미 있음(edric, adrian, kylen, gregor, marot).

## 3. 알려진 한계·유의
- 코드로 그린 도트이므로 얼굴 표정 폭이 작다. 일러스트 교체 시 위 "그림 교체" 절 참고.
- 소설 서재는 처음부터 전부 열려 있어 게임 중 스포일러가 보일 수 있다(사용자 결정).
- 본문 단락의 "아주 조금/한참/처음으로" 같은 반복 표현은 4권에서 한 번 줄였다. 10만 자 분량에서 35회 수준은 자연스럽다는 사용자 판단이 있으니 더는 손대지 말 것.
